# Within-item thinking comparison (report set, exploratory)

Generated by `node scripts/llm_within_item.mjs`. Aggregates only. For each item, its four replies (one per run) are split into replies with at least one over-claimed unanswerable answer and replies with none; items with both kinds give one difference in mean thinking tokens. The item is held fixed, so item type cannot explain the difference.

- Items: 114; with both kinds of reply: 27; over-claim in every run: 66; never: 21; no unanswerable answers: 0.
- Over-claim replies minus clean replies, same item: median 111 thinking tokens; positive in 16 of 27 items.
- Wilcoxon signed-rank, one-sided: z = 0.62, p = 0.2661; matched-pairs rank-biserial r = 0.14.
