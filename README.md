# Synthetic Cognition Lab

The Synthetic Cognition Lab studies how artificial systems sense, model and know themselves. It is an independent, experiment-first lab: every question becomes a small, runnable artifact (a simulation, a probe, a benchmark) built so that the right answer is known in advance. Claims are about methods and measured behavior only; the lab does not claim that any system is or is not conscious. Null results are reported with the same weight as positive ones, and every finding links to the artifact that produced it.
